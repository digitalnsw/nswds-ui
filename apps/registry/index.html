NSWDS Registry

shadcn component registry for @nswds/ui. JSON is served from /r.

1. Add the @nswds namespace

In your project's components.json:

{
  "registries": {
    "@nswds": "https://ui.digital.nsw.gov.au/registry/r/{name}.json"
  }
}

2. Install components

npx shadcn@latest add @nswds/button

Available: badge, button, card, field, icons, input, label, labeled-separator, link, logo, separator, spinner. The theme item (semantic token CSS variables) is installed automatically as a dependency of every component.

3. Install the design tokens (required)

Components style themselves with semantic tokens backed by @nswds/tokens. Without them, colours render unstyled: 

npm install @nswds/tokens

Then import the token layers into your Tailwind stylesheet — see the full install guide for the copy-paste CSS and dark-mode setup.
